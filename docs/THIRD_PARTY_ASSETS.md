# DEADREACH — Third-Party Asset Register

This file records third-party production assets considered or integrated into DEADREACH. Keep license evidence with the repository even when attribution is not legally required.

## Quaternius — Zombie Apocalypse Kit

**Status:** selected as the first production-art candidate for Production 0.3; binary assets not yet committed.

**Creator:** Quaternius

**Official pack:** Zombie Apocalypse Kit, March 2024

**Official license:** CC0 1.0 / public domain dedication. The creator states that the pack can be used in personal and commercial projects and that attribution is not required.

**Relevant contents:**

- 4 playable survivor characters
- 20 animations per playable character
- 4 infected/enemy characters
- rifles / shotgun / SMG / pistol and melee weapons
- street, traffic, container, debris and survival/environment props
- FBX, OBJ, glTF and Blend distributions

**DEADREACH intended initial subset:**

- one survivor character for the first production visual replacement
- Zombie Basic
- Zombie Chubby
- Zombie Arm
- Zombie Ribcage
- rifle as the first primary weapon visual
- selected street/debris props after character validation

**License/source references retained during selection:**

- https://quaternius.com/packs/zombieapocalypsekit.html
- https://quaternius.com/faq.html
- Original creator Patreon post for the pack links the downloadable distribution and states CC0/commercial use.

## Policy

- Do not copy assets into the repository unless their license permits redistribution and commercial game use.
- Prefer original-author sources over mirrors.
- Keep large models/textures under Git LFS.
- Do not mix similarly named mirror assets whose mirror-specific license differs from the original without checking each file.
- Production 0.3 is not art-complete until imported assets are tested in Unity and the runtime catalog validation passes without missing-asset warnings.
