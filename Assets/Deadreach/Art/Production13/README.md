# Production 0.13 external art sources

The assets in this folder are included to move DEADREACH away from prototype/dev-menu presentation and toward the Production 0.13 command-center art direction.

- `Quaternius/`: Modular SciFi MegaKit Standard FREE, CC0 1.0.
- `Resources/Production13/UI/`: selected rasterized elements from Kenney UI Pack: Sci-fi 2.0, CC0.

See `THIRD_PARTY_ART.txt` and per-source license files. Runtime/editor code intentionally recolors/re-materials imported meshes to the DEADREACH graphite/cyan/amber palette.
